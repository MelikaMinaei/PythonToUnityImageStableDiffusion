# PythonToUnityImageStableDiffusion
## How to Use
1. To run the server, use the commandline and type python server.py where the server.py script exists.
2. Once you see "Server started on port 50051." on commandline, start the unity project.
3. Type your prompt in the input field in Unity and hit enter.
4. To track the time it takes for the model to generate an image of the sent prompt, look at the commandline.
5. Once the image is generated and saved, you can see the change of the texture in Unity.
6. To repeat the process for another prompt, repeat steps 3-5.
Note: If you are having errors, please look at the "Diffusion Model Setup Instruction" which is written at the end of this document.

## Project Description
This project has a python server and a Unity client. The user gives Unity a prompt. Then, Unity sends the prompt to the server using gRPC. The server generates an image of the "texture of" the given prompt using stable-diffusion-2-1. Afterwards, the server saves the image and sends it back to Unity using gRPC. Once unity receives the image, it changes the main texture of the material that is used for the 3D object.

### General instruction for setting up a project with a server written in Python and a Unity client using gRPC:
1. Create a unity project
2. Make a .proto file for services, request and reply messages. For example, for sending a simple hello message you should write a proto file like this:
`syntax = "proto3";

`package helloworld;`

`service HelloService {`
    `rpc SayHello (HelloRequest) returns (HelloReply) {}`
`}`

`message HelloRequest {`
    `string name = 1;`
`}`

`message HelloReply {`
    `string message = 1;`
`}`

3. Use this command line: pip install grpcio grpcio-tools
4. To create the python server scripts from the proto file: python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. ==sendImage==.proto
	This will create 2 python files.
5. Add server script to its folder
6. Add these plugins to the unity project:
	1. Google.Protobuf.dll
	2. Google.Core.Api.dll
	3. Grpc.Core.dll
	4. System.Runtime.CompilerServices.Unsafe.dll
	5. System.Runtime.dll
	6. grpc_csharp_ext.dll
7. Add grpc_csharp_plugin.exe to where your .proto file is
8. Use protoc -I=. --csharp_out=. --grpc_out=. --plugin=protoc-gen-grpc=grpc_csharp_plugin ==sendImage==.proto to create the cs files of the proto file.
2 cs files should be created.
10. Add the generated cs files to the unity projects Assets/Scripts
11. Create your own cs file for using the channel and communicating in Unity project Assets/Scripts
12. run the server
13. run the unity project
Note: The highlighted names can differ based on your file names.


### Brief Description of Protobuffers Used in gRPC
gRPC services and messages between clients and servers are defined in proto files. The Protobuf compiler, protoc, generates client and server code that loads the .proto file into the memory at runtime and uses the in-memory schema to serialize/deserialize the binary message. After code generation, each message is exchanged between the client and remote service.
Protocol Buffers
The entire flow shows that Protobuf offers some great benefits over JSON and XML. Parsing with Protobuf requires fewer CPU resources since data is converted into a binary format, and encoded messages are lighter in size. So, messages are exchanged faster, even in machines with a slower CPU, such as mobile devices.


### Diffusion Model Setup Instruction(Written by Amirhossein Zamani)
1- Install Anaconda on Windows using the following link: 
https://docs.anaconda.com/free/anaconda/install/windows/
2- After the installation, search for “Anaconda Prompt” in your windows search bar and open 
the anaconda terminal. 
3- Create a Conda environment using the following command (you can choose the version of 
the python as you wish. Mine is 3.8.5 but I believe any version after this should work without 
any problem): 
conda create -n myenv python=3.9 
4- Then, install the Pytorch library using the following command: 
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118 
5- Then, install the diƯusers library and other required packages using the following 
command: 
pip install diffusers transformers accelerate scipy safetensors 
6- Then, run the python script (Stable_DiƯ_Test.py)

Stable_DiU_Test.py script:
```import torch
from diffusers import StableDiffusionPipeline
import random
import numpy as np

seed = 1
torch.manual_seed(seed)
torch.cuda.manual_seed(seed)
random.seed(seed)
np.random.seed(seed)
model_id = "stabilityai/stable-diffusion-2-1"
pipe = StableDiffusionPipeline.from_pretrained(model_id, torch_dtype=torch.float32)
pipe = pipe.to("cuda")
prompt = "a photo of a dog on a dining table"
image = pipe(prompt).images[0]
    
image.save(f"./{prompt}.png")```
