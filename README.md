# PythonToUnityImageStableDiffusion
## Project Description
This project has a python server and a Unity client. The user gives Unity a prompt, then Unity sends the prompt to the server using gRPC. The server generates an image of the "texture of" the given prompt using stable-diffusion-2-1. Afterwards, the server saves the image and sends it back to Unity using gRPC. Once unity receives the image, it changes the main texture of the material that is used for the 3D object.
## How to Use
1. To run the server, use the command-line interface and type `python server.py` where the server.py script exists.
2. Start the unity project once you see "`Server started on port 50051.`" on the command-line interface.
3. Type your desired prompt in the input field in Unity and hit enter.
4. To track the time it takes for the model to generate an image of the sent prompt, look at the command-line interface.
5. Once the image is generated and saved, you can see the change of the texture in Unity.
6. To repeat the process for another prompt, repeat the steps 3-5.
> [!WARNING]
> If you are having errors with running the project, please look at the [Diffusion Model Setup Instruction](#diffusion-model-setup-instruction) which is written at the end of this document.

## Project Setup with a Server (Python) and a Client (Unity) using gRPC:
1. Create a unity project.
2. Make a proto file for services, request and reply messages with `.proto` extension.
For example, to send a simple hello message, write a proto file like this:
```syntax = "proto3";
package helloworld;
service HelloService {
    rpc SayHello (HelloRequest) returns (HelloReply) {}
}

message HelloRequest {
    string name = 1;
}

message HelloReply {
    string message = 1;
}
```
3. Run `pip install grpcio grpcio-tools` in the command-line interface.
4. To create the gRPC python scripts from the proto file for the server, run this in the command-line interface:<br/>
`python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. sendImage.proto`<br/>This will create two python files: sendImage_pb2.py and sendImage_pb2_grpc.py
5. Create and add your server script to the project.
6. Add the following plugins to the unity project in Assets/Plugins:
	1. Google.Protobuf.dll
	2. Google.Core.Api.dll
	3. Grpc.Core.dll
	4. System.Runtime.CompilerServices.Unsafe.dll
	5. System.Runtime.dll
	6. grpc_csharp_ext.dll
> [!TIP]
> You can find download these files from the current project.
7. Add grpc_csharp_plugin.exe and protoc.dll to where your proto file is.
8. Use `protoc -I=. --csharp_out=. --grpc_out=. --plugin=protoc-gen-grpc=grpc_csharp_plugin sendImage.proto` in the command-line interface to create the gRPC C# scripts files from the proto file. This will create two C# files: SendImage.cs and SendImageGrpc.cs
10. Add the two generated C# files in last step to the Unity project.
11. Create your own C# files for using the channel and communicating in the Unity project.
12. Run the server.
13. Run the Unity project.

> [!CAUTION]
> The file names can differ based on your proto file name, such as "sendImage" in the commands. Please change them accordingly.
## Brief Description of Protobuffers Used in gRPC
gRPC services and messages between clients and servers are defined in proto files. The Protobuf compiler, protoc, generates client and server code that loads the .proto file into the memory at runtime and uses the in-memory schema to serialize/deserialize the binary message. After code generation, each message is exchanged between the client and remote service.
Parsing with Protobuf requires fewer CPU resources since data is converted into a binary format, and encoded messages are lighter in size. So, messages are exchanged faster, even in machines with a slower CPU, such as mobile devices.
## Diffusion Model Setup Instruction
1. Install Anaconda on Windows using the following link: 
https://docs.anaconda.com/free/anaconda/install/windows/
2. After the installation, search for “Anaconda Prompt” in your windows search bar and open 
the anaconda terminal. 
3. Create a Conda environment using the following command (you can choose the version of 
the python as you wish. Mine is 3.8.5 but I believe any version after this should work without 
any problem): 
`conda create -n myenv python=3.9`
Then run:
`conda activate myenv`
5. Then, install the Pytorch library using the following command:<br/>
`pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118`
6. Then, install the diffusers library and other required packages using the following 
command:<br/>
`pip install diffusers transformers accelerate scipy safetensors`
7. Then, run the python script (Stable_DiU_Test.py)

Stable_DiU_Test.py script:
```import torch
from diffusers import StableDiffusionPipeline
import random
import numpy as np

seed = 1
torch.manual_seed(seed)
torch.cuda.manual_seed(seed)
random.seed(seed)
np.random.seed(seed)
model_id = "stabilityai/stable-diffusion-2-1"
pipe = StableDiffusionPipeline.from_pretrained(model_id, torch_dtype=torch.float32)
pipe = pipe.to("cuda")
prompt = "a photo of a dog on a dining table"
image = pipe(prompt).images[0]
    
image.save(f"./{prompt}.png")
```
